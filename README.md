# Receitas de Programação Web (13 a 21)

Repositório dedicado às atividades e implementações das **receitas 13 até 21** da disciplina de **Programação Web**, ministrada pelo professor **Fabricio Vale**.

> Projeto Next.js com App Router e Tailwind CSS.

## Estrutura do Projeto

```
receitas-pw-13-21/
├── app/                        → Projeto Next.js completo (todas as receitas integradas)
├── Receita13/                  → Next.js: aplicação e páginas (rotas básicas, <Link>)
├── Receita14/                  → Next.js: páginas e componentes (props, sub-rota)
├── Receita15/                  → Next.js: layouts e links (layout.js aninhado)
├── Receita16/                  → Data fetching I (SSR com searchParams + OMDb API)
├── Receita17/                  → Formulário de pesquisa (next/form, mini-desafio layout)
├── Receita18/                  → Data fetching e Client Components (memo, useCallback)
├── Receita19/                  → Implementação de API (Route Handler)
├── Receita20/                  → Server Actions (formulário com título e ano)
└── Receita21/                  → Rotas dinâmicas e SSG (generateStaticParams + next/image)
```

Cada pasta contém o(s) arquivo(s) `.js` da solução e o `.html` da receita original do professor.

## Como rodar

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000` e navegue pelo menu principal.
